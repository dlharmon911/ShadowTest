# Shadow Test

## This project is a test of the shadowing capabilities of the Ogle library. It uses the Modeler library to create a simple 3D scene and then uses Ogle to render the scene with shadows.

## Dependencies
Can be found on the GitHub for the project.
Libraries required for the project: [Ogle](https://github.com/dlharmon911/libogle), [Modeler](https://github.com/dlharmon911/libmodeler)
Binary files required for the project: [Layout Compiler](https://github.com/dlharmon911/lcompiler)
